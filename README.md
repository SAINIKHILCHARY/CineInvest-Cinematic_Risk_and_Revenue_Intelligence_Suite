# CineInvest: Movie Investment Efficiency & Portfolio Risk Analytics

## Project Overview

CineInvest is a data analytics project focused on analyzing historical movie data to evaluate investment efficiency, profitability, and portfolio risk. The project uses Excel, SQL, Python (Pandas), and Power BI to clean, transform, analyze, and visualize movie industry data for business decision-making.

---

# Project Objectives

- Analyze movie financial performance.
- Identify profitable production companies and genres.
- Evaluate investment efficiency using ROI and Revenue.
- Create reusable SQL queries and business KPIs.
- Build an interactive Power BI dashboard.
